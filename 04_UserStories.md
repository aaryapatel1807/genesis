# 04_UserStories.md — Genesis User Stories

## The Judge (primary demo persona)
- As a judge, I want to type a topic and see something I've never seen before within
  60 seconds, so that Genesis stands out from forty chatbot demos.
- As a judge, I want every node and edge to show its sources, so that I trust the
  "wow" isn't just pretty confabulation.
- As a judge, I want the future simulator to be clearly labeled as simulation,
  so that I respect the team's honesty about AI limits.

## The Curious Learner
- As a student new to AI, I want to see the whole ecosystem as a universe instead of
  reading Wikipedia, so that I grasp how companies, researchers, and universities connect.
- As a learner, I want to click a node (e.g. OpenAI) and keep expanding outward with
  no dead ends, so that curiosity never hits a wall.
- As a learner, I want to drag the time slider to 2020, so that I can see what the
  field looked like before I knew it existed.

## The Analyst / Founder
- As a founder, I want to ask "what if NVIDIA disappears" and watch the cascade,
  so that I can stress-test my supply-chain assumptions visually.
- As an analyst, I want the Reality Meter on every node, so that I know which parts
  of the picture are solid and which are thin.
- As an analyst, I want to click an edge and read *why* two entities connect,
  so that I can verify claims before citing them.

## The Skeptic (edge cases we must handle)
- As a skeptic, when I expand a node and the AI finds nothing new, I want an honest
  "no further entities found" — not invented nodes.
- As a skeptic viewing the future simulator, I want it impossible to mistake the
  simulation for factual prediction.
