# 05_UserFlows.md — Genesis User Flows

## Flow 1 — Generate a World
1. User lands on homepage: "GENESIS — The Living World Model. Ask any topic."
2. Topic field is pre-filled with "Artificial Intelligence" (v1: fixed topic).
3. User clicks **Generate World**.
4. 2s suspense → the universe animates into existence: central node, categories bloom outward.
5. System message: "World generated — 64 entities, 128 connections, 41 sources."

## Flow 2 — Expand the Universe
1. User clicks a node (e.g. OpenAI).
2. Side panel opens: description, Reality Meter, connected entities.
3. User clicks **Expand**.
4. New nodes graft onto the graph with animation (≤2 live searches, cached if repeated).
5. If nothing new is found: honest empty state — "No further entities found in live search."

## Flow 3 — Time Travel
1. User drags the time slider (2020 → 2022 → 2024 → 2026).
2. Graph morphs: nodes appear/disappear, edges rewire, counts update per snapshot.
3. A caption narrates the era: "2022 — the generative boom begins."
4. Dragging back restores the present world.

## Flow 4 — Future Simulation
1. User opens the Simulator and types a scenario ("NVIDIA disappears").
2. Banner appears: **SIMULATION — AI-generated scenario, not factual prediction.**
3. Affected nodes dim/pulse; edges rewire; a cascade list explains each effect.
4. User clicks **Reset** to restore the real world.

## Flow 5 — Inspect Evidence
1. User clicks any edge → "Why connected?" panel: relation type + evidence snippets + source links.
2. User clicks any node → Reality Meter: Confidence %, Freshness, Sources count.
3. All panels link out to original sources (open in new tab).

## Flow 6 — Share / Submit (v1 minimal)
1. "Copy link" captures current view state (topic + snapshot year) via URL params.
2. README + demo video cover the hackathon submission; no in-app submission flow.
